How this works: a GitHub Actions workflow polls opensky-network.org/api/states/all for a box around Berlin every 5 minutes, triggered by a free external scheduler calling GitHub's API directly (GitHub's own native cron trigger proved unreliable on a low-traffic repo, silently throttling well below its configured interval), and commits the result to data/latest.json. This page just fetches that static file — on load, and every 60 seconds after — so there's no CORS problem and no server to run. Between fetches, each marker keeps moving on its own, dead-reckoned from its last known fix using its reported heading and speed; altitude in the table interpolates the same way using OpenSky's own reported climb/descent rate. A plane that's landed is filtered out even if OpenSky's on_ground flag hasn't flipped yet (it's known to lag right at touchdown): low altitude plus low ground speed together are treated as landed. Route info (the city each flight is coming from / heading to) is real data from adsbdb.com's free, keyless callsign lookup — OpenSky's own route endpoint refuses anonymous requests entirely, so this fills that gap; an arriving/departing flight only names the far-end city, since the Berlin end is already implied. Aircraft type (for the helicopter/private-jet/airliner icon) comes from the same source, via icao24 lookup. When adsbdb has no route on file for a callsign (common for private/GA aircraft), the narration instead shows a heuristic read of heading/altitude relative to BER, clearly distinct from real route data. Operators are matched the same way — adsbdb's airline data first, then a small built-in lookup table, then registration-style detection for all-letters callsigns. The "you might actually hear this one" narration line is also an estimate, not measured noise — BER does run a real public noise-monitoring network (31 ground stations), but it's a browser dashboard with no public API, so this page just flags a plane as plausibly audible from low altitude (and helicopters from a bit higher, since they carry further) rather than pulling real decibel readings. If the data file is ever unreachable, the dashboard falls back to a small set of animated stand-in flights, clearly marked DEMO DATA above, so the page never sits there broken.
